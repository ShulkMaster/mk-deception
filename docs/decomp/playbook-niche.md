# Matching rules: niche / stop

Prerequisite: [high protocol](playbook-high-occurrence.md), then [mid](playbook-mid-occurrence.md).
Schema: ID | IF | REQUIRE | TRY. These are not default optimizer knobs.

N01 | Boolean/rotate idiom survives honest C | Exact intrinsic semantics + unsigned contract | Proven cntlzw/rotate intrinsic, not instruction-count padding.
N02 | Global address vs contents/SDA differs | ELF object/array identity + all uses | Correct object/array/pointer declaration. No fake array solely to suppress SDA.
N03 | Repeated RTTI/null ladder | Class identity + no bl + null paths | Inline typed ladder; no guessed class/layout.
N04 | Factory cases return distinct owners | Allocation/failure semantics + case order | Direct typed returns instead of artificial shared result.
N05 | Reverse iteration/update differs | Direction, stride, zero-count semantics | Typed reverse-index walk or authentic vendor pre-decrement idiom; avoid manual byte offsets.
N06 | Peephole/CSE/scheduler residue | TU hypothesis tested + historical local-exception evidence | Investigate exact option in scratch. No per-function optimization exception during TU-settings-fixed work; no flags masking wrong source.

## Hard stops

Stop after applicable honest source check when only these remain:

- GPR/FPR coloring; parameter NV homes; declaration permutations rotate mismatch.
- li-zero vs copying an already-zero register.
- Commutative scratch-register encoding with identical semantics.
- Frameless PLATFORM mtlr/blrl emission.
- Anonymous relocation labels with verified identical payloads/targets.
- Equivalent branch/address lowering without evidence for another source form.

Unknown calls/offsets/CFG are NOT coloring: classify borked or breakthrough needed;
name missing evidence. Assembly-required target -> skip; AGENTS.md requires
explicit per-function permission for the rare sequence path.

Stop output: source TODO: [near miss] score; residual; stop reason.
Keep classification honest; explain nonmatching fallback in SHA results.
Never omit required returns, invent lifetimes/types, add empty keep arms,
fake volatile, dead sinks, register declarations, or goto to cross a ceiling.

## Optional search

Permuter only after algorithm/CFG/ABI/layout agree. Smoke-test a real near miss;
use recovered TU command. PERM_* stays in scratch. Reject undefined behavior,
wrong types, reordered effects, fake liveness even at zero score.
Mirage imports require platform-neutral behavior + GC retail/objdiff evidence.
Apply task-specific attempt counting; exemptions never waive verification.
